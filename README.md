# Hard Half

Beat the model on the hard half of LeetCode weekly contests. One page, ten problems, a stopwatch,
and the record of which AI models actually got each one accepted. The models' mistakes and the
full manual open only after you record your own attempt.

Built from the [LLM coding benchmark manuals](https://anthonykot.github.io/lc-benchmark-manuals/).

    BENCH=/path/to/benchmark python3 scripts/build_data.py
    python3 scripts/build.py
    ./verify.sh
